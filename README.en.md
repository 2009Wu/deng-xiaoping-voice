# Deng Xiaoping Voice Studio

A blue-and-white layout with side-by-side inputs and a dedicated playback and export area. The language menu lists the top 20 languages by total speakers, including Simplified and Traditional Chinese as Mandarin script options. Language switching keeps drafts in place.

Local Windows text-to-speech and song voice conversion. Extract the full ZIP, then run Start Deng Voice Studio.exe. Outputs are AI-generated.

The Windows launcher checks for updates automatically. Users on v0.1.0 need to download the new ZIP once.
